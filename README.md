# SomMark-Tools

A collection of tools built around the [SomMark](https://github.com/Adam-Elmi/SomMark) markup language.

---

## Tools

### [sommark-highlight](./SomMark-Highlight)

Syntax highlighting for SomMark. Works in the browser and in Node.js terminals. Supports static HTML output and a live editor powered by CodeMirror 6, with real-time syntax error detection.

- **npm:** `npm install sommark-highlight`
- **CDN:** `dist/sommark-highlight.js` (static) · `dist/sommark-highlight.full.js` (with live editor)

---

### [svg-to-smark](./svg-to-smark)

A browser tool that converts SVG markup into SomMark syntax. Paste any raw SVG or browse Iconify's icon library and get SomMark output instantly.

- Runs entirely in the browser — no build step
- Serve via HTTP to use (requires a local server)
